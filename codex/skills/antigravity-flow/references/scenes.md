# Scenes, clip edits, and export

1. Resolve the intended take for each shot from the storyboard or the user's selection. Open the correct Scene or create one in the verified project when requested. Use the clip menu's Add to scene or the timeline's Add clip and verify the resulting order on the timeline.
2. Use trim handles to remove an unwanted section while keeping the source take. Record the chosen boundaries and check the surrounding transitions. Preview the sequence and inspect seams where a prop, person, or motion direction changes. For a matched cut, Save frame at the actual accepted end of the clip or extract the last decoded video frame from a downloaded file.
3. Use Extend or the edit composer only if the requested setting is available. Describe what should change and what needs to carry through. Verify the current credit cost, submit within scope, and inspect the resulting take and seam before adopting it.
4. Use the editor's Download media or the asset's Download menu. Choose the requested tier; check the live label, eligibility and cost of upscaling. Download the full scene only if requested. Wait for completion and verify the local output path, file type, and expected duration and size using an available media probe. A detected audio track is a technical check; listening or transcription is a separate check.
5. Deliver the local path and note any trimmed, missing, or unverified sections. Sharing links, publishing to YouTube, trashing assets, and downloading an entire project are separate operations requiring appropriate user scope.

See [Edit videos and build scenes](https://support.google.com/flow/answer/16935718?hl=en).
