# Projects and Ingredients

1. Open the verified existing project. Create a new project or collection only within the requested setup. Record its title and URL so the next stage uses the same project.
2. Identify reusable local and in-project assets before uploading duplicates. For each local file, verify its path and format, determine its use, and upload only the intended file with the documented browser chooser. Wait for the upload to finish and verify the result in project media or the prompt picker.
3. Use the Characters library or the visible Create character control to reuse a matching Character or create one through Flow. Distinguish a saved Character from a standalone image. If the project requires both, attach both and verify the Character badge and matching source image independently.
4. For a new image or Character generation, use the current model and available settings, apply the skill's credit check, inspect the result, and confirm it is saved in the intended library. A neutral background and uncluttered silhouette make a practical identity reference.
5. Record each ingredient's project name, category, source, and verified status in the storyboard or asset list. Access to the project does not grant permission to share it or to use its media in another service.

See [Flow asset and project management](https://support.google.com/flow/answer/16935308?hl=en).
