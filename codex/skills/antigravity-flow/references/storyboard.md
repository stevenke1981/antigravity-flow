# Storyboard and prompts

Read the brief and any existing storyboard before proposing a new structure. Keep the requested running time, framing, format, dialogue language, budget, platform, and house style. Use the project's existing planning format when available.

## Plan the shots

- Define recurring identities separately from motion references. Give each cast member, prop, location, and style anchor a stable name, source asset or prompt, and concrete traits to preserve.
- For each shot record the ID, duration, framing, action, prompt, audio cues, incoming and outgoing state, reference roles or timestamps, Flow mode, model, resolution, aspect ratio, variants, and status. Distinguish required settings from suggestions.
- Use Ingredients when the shot relies on reusable cast, prop, style, or scene references. Use Frames when the requested result should be anchored to start or end pictures and the selected model supports the needed slots.
- Match the preceding accepted clip's actual last frame when the action continues across clips. Record who holds which prop, its position and orientation, screen direction, and the action that has already happened. Plan an establishing or insert shot where a motivated cut works better.
- Check model compatibility only where it matters. In a draft, list an option as provisional until the live picker or official documentation confirms the feature. See [Flow models and compatibility](https://support.google.com/flow/answer/16352836?hl=en).

## Draft a usable prompt

Use a clear camera position and a single main move or a locked camera. Name the visible subject, concrete action in order, setting, lighting, and required visual details. Fit the physical action to the available duration. Tie a sound to its source and bind each line of dialogue to its visible speaker.

For example, a four-second handoff can spend the first beat establishing the object in one character's hands, the middle beat showing contact and release, and the last beat holding on the new owner. Keep the same prop visible through the exchange. Where a storyboard specifies a different reference for each second, label the images in order and maintain the project's full required reference coverage.
